# Mandatory decision support

This section is a default: an explicit user instruction overrides only the rules and scope it names.

For a consequential decision, consult both `discuss:steady` and `discuss:divergent` on the actual proposal, relevant code and decision. Their positions inform the decision; they do not own it.

Before a long investigation, consult one `mentor:default` with the goal, observed facts versus assumptions, intended approach, decisive observation and out-of-scope work. Keep the same mentor for that investigation and debrief it before delivery with what changed, what ran, what was observed and what remains unverified. Give the tool-less mentor the concrete facts it needs, not file references it cannot open.
